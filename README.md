# Python Chapter 5 — Dictionaries and Sets

This repository contains my practice programs and exercises from **Python Chapter 5**. This chapter focuses on working with dictionaries and sets, along with their commonly used methods and operations.

## Topics Covered

### 1. Dictionaries

Learn how to create and work with dictionaries in Python.

Practice includes:

- Creating dictionaries
- Key-value pairs
- Accessing values using keys
- Adding new key-value pairs
- Updating values
- Removing key-value pairs
- Checking dictionary contents

Example:

```python
student = {
    "name": "John",
    "age": 20,
    "course": "Python"
}
```

### 2. Dictionary Methods

Practice commonly used dictionary methods, including:

- `keys()`
- `values()`
- `items()`
- `get()`
- `update()`
- `pop()`
- `popitem()`
- `clear()`

### 3. Sets

Learn how to create and work with sets in Python.

Practice includes:

- Creating sets
- Adding elements
- Removing elements
- Understanding unique elements
- Working with set operations

Example:

```python
numbers = {1, 2, 3, 4, 5}
```

### 4. Set Methods

Practice commonly used set methods, including:

- `add()`
- `remove()`
- `discard()`
- `pop()`
- `clear()`
- `update()`

### 5. Union

Learn how to combine the unique elements from two or more sets using union operations.

Example:

```python
a.union(b)
```

### 6. Intersection

Learn how to find the elements that are common between two or more sets.

Example:

```python
a.intersection(b)
```

## Topics Practiced

- Python dictionaries
- Key-value pairs
- Dictionary methods
- Python sets
- Set methods
- Unique elements
- Union
- Intersection
- Set operations

## Learning Goal

The goal of this chapter is to understand how dictionaries and sets work in Python and become comfortable using their methods and common operations such as union and intersection.
